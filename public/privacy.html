pls,fix privacy

What the add-in stores, where, and for how long.

Linked objects through a relay (hosted builds only)

The pls,fix from GitHub has no relay: its links always move by copy and paste on your computer (below). A build hosted on its own server can also send them through an encrypted relay. Sending a range, table, chart or cell from Excel to PowerPoint that way encrypts it in the Excel pane first (AES-GCM, with keys derived from a per-link token that lives only in the workbook's own registry and in the tags on the PowerPoint shape). The relay server stores that ciphertext plus a one-way hash of the access key (sha256(authKey)) - never the plaintext content, a file name, a workbook name or a person's name. PowerPoint downloads the ciphertext and decrypts it in its own pane.

A link is kept for 30 days after its last update; a PowerPoint inbox item (an export waiting to be pasted in) for 7 days. After that it is deleted on the next hourly sweep.

Local mode (no relay)

With Copy and paste on this computer (the only way in the pls,fix from GitHub, the default everywhere), nothing is sent anywhere: Excel copies a link to the clipboard instead of uploading it, and PowerPoint reads it back from what you paste. Pasted links are kept in this browser's own IndexedDB (plsfix-links) until you press Clear pasted links, or the oldest ones are dropped once that store passes 32 MB.

A copied bundle carries the same live link tokens as the picture it came from: paste it into PowerPoint, do not forward it on.

What Excel and PowerPoint save on the computer

A few settings ride with the workbook itself, in Excel's own workbook.settings, so they travel with the file:

  • plsfix.brand.v1 - the brand palette, fonts and currency style
  • PLSFIX_PAINT_SLOTS_V1 - the three captured format-paint slots
  • PLSFIX_AUTOPUSH - whether an edit re-sends its linked objects automatically
  • PLSFIX_LINK_HIGHLIGHT - whether linked ranges are tinted on screen
  • smtAuditOverlay - which cells the model-audit stripes currently cover
  • PLSFIX_LINKS - the workbook's own registry of what it has linked out

A handful of small values are kept on the machine instead (Office's own storage, or the browser's localStorage when that is all a host offers):

  • plsfix.link.workspace.v1 - the pairing key an Excel workbook and a PowerPoint deck share, so an exported item opens only on a paired pane
  • plsfix.brand.v1 - the same palette, as a fallback for a workbook that has not saved its own yet
  • plsfix.paint.v1 - the same paint slots, for the same reason
  • plsfix.firstRun.v1 / plsfix.firstRun.ppt.v1 - whether the "New here?" card has already been dismissed on this machine

What pls,fix does not do

No telemetry, no analytics, no cookies. The only network requests the panes make are to load themselves and, in a hosted build that uses it, to the relay above; nothing is sent to a third party.
