pls,fix support

Fast, consistent financial modelling tools for Excel, and tracked links that carry a range, table or chart from a workbook onto a PowerPoint slide and keep it up to date.

Where it runs

pls,fix has two panes: a task pane in Excel with the modelling tools, and a task pane in PowerPoint for the linked objects a workbook has sent it. Both load from the same hosted add-in - nothing is installed on the computer.

Requirements: Excel and PowerPoint with Microsoft 365, or Excel 2019 and PowerPoint 2021 or later, on Windows, Mac or the web.

Reporting a problem

When something goes wrong, pls,fix shows a red message with a Copy details button. Click it, then send what was copied to the pls,fix owner. That text already carries what happened and where - no need to describe it separately, and nothing on this page asks for a personal e-mail address.

Excel functions

The custom functions, all under the PLSFIX namespace. They run in the same pane as everything else, so no extra add-in or runtime is involved.

=PLSFIX.ROUND(range, index, decimals)

One cell's share of a consistently rounded group: the rounded values add up to the rounded total.

=PLSFIX.ROUNDSUM(range, decimals)

The group's total, rounded so it equals the sum of PLSFIX.ROUND over the same range.

=PLSFIX.CAGR(first, last, periods)from v2.7

The compound annual growth rate from first to last over the given number of periods.
